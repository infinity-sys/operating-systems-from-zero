# Pharos Cloud dataset (fictional)

Pharos Cloud is a made-up hosting company; its server is called pharos-01. All data is generated by `make_pharos.py` with seed 1969 (`python3 make_pharos.py` regenerates identical files).

| File | What it holds |
|---|---|
| `processes.csv` | 48 jobs: pid, name, user, kind (web, system, batch, db, ml, backup), arrival_ms, burst_ms, priority, memory_mb, io_bound — used in the process and scheduling episodes |
| `page_refs.csv` | Three page-reference strings (A, B, C), 20 references each, pages 0–7 — page replacement episodes |
| `disk_requests.csv` | 10 cylinder requests, head starts at 52, disk 0–199 — disk scheduling |
| `banker.csv` | Allocation and Max for P0–P4 over resources A, B, C — Banker's algorithm |
| `resources.csv` | Total and Available for A, B, C (safe order P3, P0, P1, P2, P4) |
