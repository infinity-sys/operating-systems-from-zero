# Operating Systems: From Zero to Hero

Code and datasets for every episode of the Infinity Systems YouTube course
**Operating Systems: From Zero to Hero**.

Made for **computer science students first**, and for anyone curious about
what really happens inside their computer. It starts from zero and builds up
to everything an operating systems course examines: processes and threads,
CPU scheduling, synchronization and deadlocks, memory and virtual memory,
storage, file systems and I/O, protection, security and virtualization —
each one worked by hand, exam style, then in real Python.

## Layout

- `data/` — the fictional **Pharos Cloud** dataset used across the whole
  course (jobs, page-reference strings, disk requests, Banker's tables),
  generated by `make_pharos.py` (seed 1969). Completely fictional.
- `episodes/E01/`, `episodes/E02/`, … — the exact code shown in each
  episode, one folder per episode, each with its own README linking the video.

## Install

You need Python 3.10+ and pandas.

- **macOS:** `brew install python` (or use the python.org installer), then `pip3 install pandas`
- **Windows:** install WSL2 (`wsl --install` in PowerShell), open Ubuntu, then `sudo apt install python3-pip && pip3 install pandas`. Several episodes use Unix-only calls such as `fork`, so use WSL2, not plain Windows Python.
- **Linux:** `sudo apt install python3-pip` (or your distribution's equivalent), then `pip3 install pandas`

```bash
git clone https://github.com/infinity-sys/operating-systems-from-zero.git
cd operating-systems-from-zero/episodes/E01
python3 three_jobs.py
```
